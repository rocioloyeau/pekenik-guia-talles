# Blog técnico - Diplomatura Coderhouse

Repositorio de la entrega de "Mentalidad de Crecimiento y Comunicación en
Entornos Digitales". Documenta un desafío real detectado al implementar la
Propuesta 1 (guía visual de talles) del CX audit de Peke Nik & Mami: la v1
de la guía no reflejaba cómo Vane asesora realmente (edad + peso + variación
por marca), y hubo que rehacerla a partir de su feedback.

Ver la entrada completa en [`docs/blog-post.md`](docs/blog-post.md).

## Publicar en GitHub Pages

1. Crear un repositorio público en GitHub (por ejemplo `pekenik-guia-talles`).
2. `git remote add origin https://github.com/TU-USUARIO/pekenik-guia-talles.git`
3. `git push -u origin main`
4. En el repo: Settings → Pages → Source: `main` branch, carpeta `/ (root)`.
5. La URL pública queda en `https://TU-USUARIO.github.io/pekenik-guia-talles/`.
