# KPI vinculado a esta guia (Plan de Medicion del CX audit)

**KPI 3 - Porcentaje de cambios por talle incorrecto**

Formula: (Cambios por talle incorrecto / Total de cambios realizados) x 100

Justificacion (del CX audit real): durante la entrevista se identifico que
los cambios mas frecuentes se producen por talle incorrecto, especialmente
cuando la compra corresponde a un regalo.

Fuente de datos: registro de cambios en planilla + motivo declarado por el
cliente al realizar el cambio.

Como se relaciona con este fix: la v1 de la guia (solo edad) probablemente
no habria movido este KPI, porque no ataca la causa real (variacion de
escala entre marcas). La v2 (edad + peso + aviso de variacion) es la que
tiene una hipotesis de impacto directa sobre este numero.
